# Project Documentation

## Overview

This directory contains documentation for the
Smart Virtual Assistant project developed by Team 05
for the CSC10014 course.

## Purpose

The documentation helps team members understand
the project structure, responsibilities, and
collaboration workflow.

## Files

- `README.md`: Overview of the documentation directory.
- `team.md`: Team member information and assigned roles.

## Collaboration

All team members contribute through individual
Git branches and Pull Requests.

Changes should be reviewed before being merged
into the main branch.

## Future Documentation

Additional project documentation may be added
as the Smart Virtual Assistant develops.

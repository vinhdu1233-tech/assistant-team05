## GitHub Workflow

1. Each member creates a separate branch.
2. Each member works on their assigned files.
3. Changes are committed and pushed to GitHub.
4. Each member opens a Pull Request to main.
5. Another team member reviews the changes.
6. Approved Pull Requests are merged into main.

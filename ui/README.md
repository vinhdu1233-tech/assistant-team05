# User Interface Plan

## Overview
The Smart Virtual Assistant will provide a simple
and user-friendly interface for students to ask
questions about campus offices and opening hours.

## Target Users
- Students who need information about campus offices.
- New students who are unfamiliar with campus services.

## Planned Features
- A text input field for entering questions.
- A submit button to send the question.
- A response area displaying the assistant's answer.
- Clear and accessible instructions for users.

## User Interaction Flow
1. The user opens the assistant interface.
2. The user types a question, such as
   "Where is the IT helpdesk?"
3. The user submits the question.
4. The assistant displays the relevant office information.

## Future Implementation
A lightweight Python UI framework such as Streamlit
or Gradio may be considered in later development stages.
The final choice has not yet been made.

## Current Status
This document describes the proposed user interface.
The actual UI has not yet been implemented as part of Lab 1.
